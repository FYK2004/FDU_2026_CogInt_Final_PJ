# 项目初步方案

> 课程：认知智能前沿技术与实践（期末项目）
> 选题类别：真实事件预测
> 预测题目：**Anthropic 是否会在 2026 年 12 月 15 日前正式 IPO？**
> 方案版本：v1，2026-10-07

---

## 1. 题目来源与问题定义

**题目来源。** Polymarket 事件 `anthropic-ipo-by`（event id `549019`，标题 “Anthropic IPO by \_\_?”），
其下共 10 个按不同截止日切分的子市场。本项目选择 `december-15-2026` 子市场作为
预测标的，因为它是当前成交与关注度较高的活跃节点之一（另两个为 `november-30-2026`、
`december-31-2026`）。

**问题定义。** 令 `T = 2026-12-15`。我们要估计

    P(Anthropic 在 T 当日或之前完成正式 IPO，并已在公开市场开始交易)

其中“正式 IPO 完成”以**首个交易日实际发生**为准（而不是以递交材料、定价或
媒体宣布为准）。除单点概率外，模型还需输出**挂牌日期的分布**与若干**条件概率**，
以便与市场价格对照。

**为什么这道题适合做认知智能课程的项目。**

1. 事件是**单公司、单里程碑**的，Yes/No 定义清晰，不存在口径模糊；
2. 事件存在**可观测的证据链**（S-1 递交、招股书披露、承销团、路演、定价），
   因此可以做“证据驱动的因果推理”，而不是纯统计外推；
3. 事件同时有**成熟的预测市场报价**，提供了一个可对照的“市场基准”，
   使我们可以量化“推理模型相对价格聚合机制是否有增量信息”；
4. 事件在课程周期内会**真实结算**，预测结果可被客观检验。

## 2. 基本设计思想

### 2.1 把 IPO 看作“里程碑门控”的过程，而不是无记忆的随机事件

常见的简单做法是把“某天完成 IPO”建模为每日常数概率的伯努利试验（等价于
几何分布 / 泊松过程）。这样得到的生存曲线是指数形状，与 Polymarket 期限结构上
明显的 **S 形**不符，也无法利用“某道门被公开证据锁定”这一信息。

因此本项目的基本设计思想是：**显式建模 IPO 必须依次通过的里程碑门**

    秘密递交 S-1  →  公开招股书 / 投资人说明日会  →  正式路演  →  簿记定价  →  首个交易日

只对每个阶段的**历时**建模，并把已被公开证据锁定的日期当作**硬约束**（条件点）。
这样模型在出现新证据时可以**条件化更新**，而市场价格只能被动重定价。

### 2.2 双信息源互相独立，再做融合

- **模型侧**：参数全部来自公开报道的证据链，**不拟合市场价格**，因此可以看作
  与市场相互独立的“第二意见”；
- **市场侧**：Polymarket 的期限结构本身就是一组被货币化的集体信念，可直接
  当作 CDF 使用；
- 两者用 **log-odds 加权**融合，权重显式暴露为超参数并做敏感性分析。

### 2.3 项目真正的卖点：可计算的条件推理

市场价格只能给出“某日期前的边际概率”。而门控模型天然支持反事实查询，例如

> 若感恩节（2026-11-26）前仍未能挂牌，则 12/15 前完成挂牌的（条件）概率是多少？

这类条件概率是市场报价**结构上无法提供**的，也是本项目相对“读报价”的核心增量。

## 3. 算法 / 模型基本框架

### 3.1 随机时间线

对第 i 条蒙特卡洛路径，挂牌日

    D_i = t0 + Δ_gap,i + Δ_road,i + Δ_lag,i (+ Δ_slip,i)

其中：

- `t0 = 2026-10-14`：Bloomberg 报道并经邀请函证实的“旧金山总部 Pre-IPO
  投资人说明日会”。这是当前时间线上**最靠近今天、且已被公开证据锁定**的门。
- `Δ_gap`：说明日会 → 正式路演启动（日历日）。参考锚点是报道的“路演最快
  11 月 9 日当周启动”，即 `t0 + 26 天`。
- `Δ_road`：路演 + 簿记 + 定价的总时长。超大型项目簿记期约两周。
- `Δ_lag`：定价 → 首个交易日（T+1 为主）。
- `Δ_slip`：**延期支线**。以概率 `slip_share` 触发，模拟“路演结束后仍未定价、
  需重新接触投资人 / 补充材料 / 等待窗口”的情况，使少量路径落到 12 月上中旬。

### 3.2 分布假设与离散化约束

- 各阶段历时取 **三角分布**（下界、众数、上界）。选用三角分布的原因：三点估计
  可直接由公开报道和行业经验给出，且右尾有限——符合“监管与承销流程不会无限
  拖延，但可能整周顺延”的直觉；
- 由于日期是**离散**的：路演启动日 snap 到**最近的周一**（IPO 路演不在周末启动）；
  挂牌日 snap 到**工作日**，并**避开感恩节当天**（美国市场休市）。

### 3.3 参数校准

先验参数（`docs` 第 3.1–3.2 节的取值）给出的基线模型**系统性偏慢**：中位挂牌日
落在 11/30，而市场期限结构隐含的中位挂牌日是 11/26 前后。因此对
`(stall_prob, gap_mode, gap_high, roadshow_high)` 做**三阶段网格搜索**，
目标函数为对活跃节点的**加权平方误差**（单位 pp²）。

校准的关键纪律：**校准结果必须能用公开证据解释，否则只算拟合**。

### 3.4 与市场融合

    p_final = σ( w · logit(p_model) + (1 − w) · logit(p_market) )

取 `w = 0.35`（偏向市场：模型只用公开证据、且校准用到了同一批报价，存在过拟合
风险，因此不取等权）。输出 80% 区间 = 参数邻域 × 权重的包络。

## 4. 数据采集方案

| 数据源 | 接口 / 方式 | 采集内容 | 规模 |
|---|---|---|---|
| Polymarket | Gamma API `/events`、`/markets` | 事件与 10 个子市场的元数据、成交量、流动性、买卖价差 | 1 个事件 / 10 个市场 |
| Polymarket | CLOB API `/prices-history` | 每个子市场的小时级价格历史（用于跳变检测与图 2） | 10 节点 × 约 720 点 |
| Kalshi | 公开 API | `KXOAIANTH-40`：Anthropic 是否先于 OpenAI 上市 | 1 个市场 |
| 新闻 | Google News RSS（4 组查询词） | 标题、来源、发布时间、链接 | 286 条索引 |
| 新闻正文 | 直接抓取 + 正文抽取 | 关键报道原文，用于证据时间线 | 15 篇留存 / 5 篇中文正文可用 |

**已知限制。** Reuters / WSJ / Bloomberg 有付费墙，正文无法直接抓取，只能依赖
二手转述（中央社、工商时报、INSIDE、Yahoo Finance 等）与 RSS 标题；已用
“多家独立来源交叉印证 + 只采信被至少两家转述的要点”来降低风险。

## 5. 业务流程

    采集（Polymarket / Kalshi / News）
      → 清洗与对齐（期限结构表、宽表历史、跳变检测、新闻索引）
      → 建立证据时间线，把“已被锁定的门”写成模型硬约束
      → 蒙特卡洛模拟（40 万条路径）得到基线生存曲线
      → 参数校准（三阶段网格搜索 + 敏感性曲面）
      → 与市场 log-odds 融合 → 最终概率 + 区间 + 情景分析
      → 出图与报告
