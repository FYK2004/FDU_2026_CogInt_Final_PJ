## 数据与复现

旧价格接口返回403，已迁移到官方Data API v2，增加显式时间范围、分页、防重复游标、
价格边界与截止过滤。原始响应和规范化历史分别留存。采齐全部节点后才发布快照，
不以当前盘口代替历史盘口。原有本地代理不再写死，恢复TLS证书验证，限制重试。

新闻按发布时间过滤，核实补录与历史索引离线合并。缺失成交量不再填0；缺测跨日价格
变化不冒充日度跳变。历史按实际观测点对齐，没有前向填充，末个UTC日可能未完结。

统一根目录，新增run_pipeline.py和requirements.txt，可离线一键运行。报告数值由
build_report_markdown.py生成，7张图均从当前结果重建；旧产物单独归档。

## 验证

18项回归测试覆盖关键边界、概率质量、吸收态、节假日、非法参数、CDF、危险率、
缺测跳变、Yes顺序、v2分页与时区，并核对最终意见池确实使用未校准证据模型。
运行命令为python -X utf8 -m unittest discover -s tests -v。
完整离线流水线已运行并检查图表。随机种子固定，科学数值可复现；执行时间字段正常变化。

## 仍需研究的部分

三角分布、阶段独立性、0.12失败率和0.35融合权重均未从历史样本验证。少量期限报价
不能唯一识别多个参数。11/09时程约束可能被后续公告推翻，常规交易日历不涵盖临时休市。
后续应采集同类IPO流程与结算结果，在跨事件样本外数据上比较市场、证据模型与意见池，
再决定权重和概率校准方法。当前不声称已经提升真实预测准确率。
