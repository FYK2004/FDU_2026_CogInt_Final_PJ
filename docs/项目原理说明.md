# 项目算法原理 v2

本项目估计Anthropic在2026-12-15美东23:59前挂牌并开放交易的概率。
当前数值见项目报告与forecast.json。原版说明保存在data/archive/2026-10-07/docs/，
其中部分方法与数值已废止。

## 信息截止与日期

project_config.py统一根目录与信息日。10/14美东日终的排他截止是10/15 04:00 UTC，
即北京时间10/15 12:00。合约December 15包含当天，不能因UTC endDate为12/16就多算一天。
新闻按发布时间过滤，历史价格严格限制在截止之前；抓取时间与信息日分别记录。

## 期限CDF与危险率

同结算规则的不同期限价格视为挂牌时间T的CDF近似F(t)。费用、风险偏好和流动性
可能使价格偏离客观概率，不能把无套利等同于概率真值。CDF必须非递减；倒挂时采用
等权PAVA修复，并保留原价与调整幅度。

    S(t) = 1-F(t)
    h = -ln(S(t1)/S(t0))/(t1-t0)

h为每日强度；annualized_hazard_pct为h×365×100。原代码误用累计概率F的比率，
且只在价格下降时计算。缺失成交量与流动性保留为空，不能用0代替。

## 流程模拟

    T = investor_day + gap + roadshow + listing_lag + optional_slip

各段为三角分布，保存完整(下界,众数,上界)，单位日历日。默认gap=(26,26,55)，
将11/09作为路演最早启动的情景假设；这不是公司承诺，后续证据可推翻。
原代码声称限制下界却仍使用16，现已统一实现与解释。

路演启动与挂牌避开周末及美国股票交易所整日休市。11/27、12/24虽提前收市，仍是交易日。
原函数_snap_to_monday仅将周末顺延，从未把普通工作日都改到周一；“只在周一挂牌”的
解释已删除。日历支持常规假日，临时休市需要补录。

stall为与各段历时独立的失败吸收态，在任何未来日期都不算挂牌；普通延期与跨年挂牌
由gap、slip建模。原代码将失败路径塞到2027-06-30，导致远期CDF错误跳到1，现已取消。

## 概率与日期分位数

CDF为P(T≤deadline)，cdf_before(day)为P(T<day)。分桶固定为[lo,hi)，最后hi为空的一桶
包括更晚挂牌与吸收态失败，确保总质量为1，避免12/01和12/16等边界重复计数。
日期分位数以未进入失败态为条件，全流产时返回null。市场无条件分位数与模型条件
分位数不同，不能直接比较。

## 市场拟合与最终意见池

联合搜索gap众数、gap上界、roadshow上界、延期占比、失败率。每种时间线只模拟一次，
其余失败率通过(1-stall)倍的条件CDF计算，减少重复模拟。情景使用共同随机数，
最终40万路径重算损失。12/15目标节点从参数搜索留出；邻近节点仍有相关信息，
因此不是独立事件样本外验证。少数报价不足以唯一确定多个流程参数。

最终使用证据模型而非拟合后模型：

    p_final = sigmoid(w*logit(p_evidence)+(1-w)*logit(p_market))

w=0.35为显式主观权重，尚未验证。两者可能共享新闻；本式是意见池，不能声称是
独立信息的贝叶斯更新。拟合模型接近报价不等于能准确预测事件。

敏感性范围枚举stall=.09/.12/.15、gap上界48/55/62、slip=0/.1、w=.25/.35/.5，
不保证80%覆盖率。蒙特卡洛标准误仅反映数值抽样噪声，不等于概率的不确定性。

## 条件概率与更新

    P(t<T≤D | T>t) = (F(D)-F(t))/(1-F(t))

市场和模型均可推算同类条件概率。市场缺少精确日期节点时采用线性插值，这是
密度假设，不能自动称为上界。分母为0时返回null。路演顺延是反事实时间线情景，
不是已完成的在线贝叶斯更新。

data/updates/2026-10-14.json记录来源、时间、核实级别与排除项。财务消息没有通过
历史样本估计的似然比，故不按正面标题人为加分。后续更新必须核实是否已交易、
所处流程、时程假设是否仍成立，再采集相应信息日的数据。

需要跨IPO历史数据和样本外评估才能判断概率是否更准确。事件结算后计算Brier分数
与对数损失；单一事件只能检验一次结果，不能充分证明概率校准。
